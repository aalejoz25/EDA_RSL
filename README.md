# Aplicaciones de Inteligencia Artificial, Visión por Computador y Machine Learning en Agricultura: Una Revisión Sistemática de Literatura

## Descripción del Proyecto

Este repositorio contiene el código y análisis para una **Revisión Sistemática de Literatura (RSL)** que examina las aplicaciones emergentes de inteligencia artificial, visión por computador y machine learning en el sector agrícola, con especial enfoque en la detección de enfermedades en plantas, evaluación de calidad nutricional y optimización de procesos agrícolas.

## Objetivo de la Investigación

El sector agrícola enfrenta desafíos significativos relacionados con la seguridad alimentaria, la sostenibilidad y la eficiencia productiva. La inteligencia artificial y las tecnologías de visión por computador han emergido como herramientas prometedoras para abordar estos retos, ofreciendo soluciones innovadoras para el monitoreo de cultivos, detección temprana de enfermedades, evaluación de calidad nutricional y optimización de recursos. Esta revisión sistemática busca identificar, analizar y sintetizar el estado del arte en la aplicación de estas tecnologías en el contexto agrícola.

## Metodología

Este estudio sigue los protocolos establecidos para revisiones sistemáticas de literatura, incluyendo:

- **Protocolo de revisión**: Definir y refinar las preguntas de investigación (PI) de forma clara y precisa
- **Estrategia de búsqueda**: Tesauro de conceptos
- **Ecuación de búsquedas**: Proceso de filtrado de artículos
- **Selección de artículos más relevantes**
- **Extracción de datos y síntesis**
- **Opcional: realizar búsqueda derivada por referencias**

## Herramientas de Análisis

Este repositorio incluye herramientas automatizadas para:

- Extracción y consolidación de datos bibliográficos
- Análisis bibliométrico y cientométrico
- Modelado de tópicos usando Latent Dirichlet Allocation (LDA)
- Análisis de redes de co-autoría y co-ocurrencia de palabras clave
- Enriquecimiento de datos mediante APIs (CrossRef, OpenAlex, Scimago)
- Visualización de tendencias y patrones de investigación
